# Product Requirements Document: AI Career Copilot

## Objective
Help Indian students/freshers bridge skill gaps for target roles with explainable recommendations.

## Core User Journey
1. Sign in.
2. Upload resume.
3. Select target role.
4. Receive fit score, gap, roadmap, project recommendations.
5. Track progress and provide feedback.

## MVP Metrics
- Time-to-first-analysis < 2 minutes.
- Recommendation helpfulness feedback >= 60%.
- Weekly active users retention trend positive in pilot.
